## 电脑用户：统一部署启动包

1. 下载 [IP知识系统-桌面启动包.zip](IP知识系统-桌面启动包.zip) 并解压。
2. 将真正包含《启动IP知识系统.md》的文件夹路径交给能读写文件、执行命令的AI，说“启动IP知识系统”。
3. AI先检查并部署，再按本人信息渐进建档；软件若要求信任或重载，按实际提示完成。

桌面包v0.1含同源检索引擎、部署工具、通用内容检查器与更新保护。默认关键词能力；语义与重排需合法模型和额外依赖并单独验收。没有软件内实测，不声称已经自动调用；不包含维护者私库、原文或客户资料。手机/纯云端聊天使用手机启动包，不执行电脑程序。

升级仍保留本人资料：新包先预演、冲突停止、备份后更新，再重验。包的哈希及能力范围见 [桌面启动包清单](桌面启动包清单.json)。

## 怎么开始

1. 读取[使用说明](交付物/使用说明.md)，让能读取文件的AI加载[工作入口](交付物/SKILL.md)。
2. 为当前IP建立或指定自己的档案，不混用其他人的经历、称呼与口吻。
3. 给出本次平台、受众、目标与真实素材，按对应流程完成内容。
4. 成稿、制作和发布状态分开记录，发布范围沿用用户实际授权。
5. 用真实反馈更新当前IP的判断，通用方法更新保留版本与适用边界。

普通云端对话不会因为拿到本地路径就读取桌面文件；只能使用实际提供或已连接的材料。本项目不自动安装连接器、同步私核、发布文章或调用视频生成。
