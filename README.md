# ayou-ip-coach · 阿柚 IP 陪跑教练系统

> 给创作者和 IP 操盘手的 AI 技能包：把文件夹装进 AI，AI 就拥有"判断该做什么 + 怎么说动用户 + 怎么复盘迭代"的一套完整打法。

## 这套系统是什么

一句话：**用一套工程化的机制（壳），装进我们逐字读完的顶级方法论（馅）。**

- **壳（机制）**：参考 ip-strategist（耳总）的成熟机制——档案驱动、对赌契约、复盘沉淀、断点续访、一个入口只加载一个任务。
- **馅（内容）**：我们自己的体系——来自《真需求》《超级符号就是超级创意》《定位》《秒赞》等**公开出版书**的蒸馏（可商用，标注来源即可），以及操盘手自己的判断规则。
- **私核（不随包发）**：安先生/经纬的课程方法论、客户名单与商业数据、对客户的定制打法——只留本机，永不进交付包。

## 三种用法（同一套东西）

1. **阿柚自己用**：放在 WorkBuddy / Claude 的技能目录，帮我干活时自动生效。
2. **发给客户**：客户把「交付物」文件夹放进他自己的 AI 技能目录，对 AI 说"开始帮我做 IP"，就获得这套打法。
3. **作为服务交付物**：付费客户收到的是带他名字水印的定制版，配合持续更新 = 服务锁定。

## 开源与商业模式（v0.2 定稿）

- **开源范围**：「交付物」目录（通用方法体系）以 **CC BY-NC-SA 4.0** 协议开源——可分享、可修改，但必须署名「阿柚 / ayou-ip-coach」、禁止商用、修改版必须同协议公开。
- **不开源（私核）**：①安先生/经纬等付费课程方法论（只作本人私下给客户服务用）②客户商业数据 ③对客户的定制判断。
- **收费产品线**：a) 专属 IP 档案库服务（主营收费：采访+编导经验帮客户理顺人格→产出客户专属 IP 档案进他的 AI） b) 档案定期校准 + 陪跑（续费）。
- **开源是获客，定制是收费**：开源系统人人可拿；你的差异化与护城河 = 访谈提炼手艺 + 对每个客户的持续理解 + 持续更新。

## 内容来源声明（诚实与合规）

- 手册内的判断条目：方法来自公开出版书（标书名/章节，可回查），加工与编排是我们自己的。
- **不含**任何付费课程（安先生/经纬）的原文或转述——那些只在私核里，当面给客户服务时用，不进文件。
- 不编造资质、数据、案例、疗效、收益。
- 高风险领域（医疗/心理/法律/财务）内容只做表达框架，不替代持牌专业意见；使用本系统产生的决策责任在使用者。

## 防盗设计（开源后依然成立的边界）

1. 开源的是"通用方法"，不是"对你的理解"——**专属 IP 档案是每个客户独有、随人走的**，这无法被开源。
2. 付费课程方法论不进开源范围。
3. 持续更新 + 定制服务锁定。
