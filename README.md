## 怎么开始

1. 读取[使用说明](交付物/使用说明.md)，让能读取文件的AI加载[工作入口](交付物/SKILL.md)。
2. 为当前IP建立或指定自己的档案，不混用其他人的经历、称呼与口吻。
3. 给出本次平台、受众、目标与真实素材，按对应流程完成内容。
4. 成稿、制作和发布状态分开记录，发布范围沿用用户实际授权。
5. 用真实反馈更新当前IP的判断，通用方法更新保留版本与适用边界。

普通云端对话不会因为拿到本地路径就读取桌面文件；只能使用实际提供或已连接的材料。本项目不自动安装连接器、同步私核、发布文章或调用视频生成。
