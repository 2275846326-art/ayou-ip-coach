# 00 · 心法与判断纪律（总纲）

> 本手册是五本手册的地基。其他手册教"怎么做对"，本手册教"判断之前默认装哪套操作系统"。方法来自公开书蒸馏，标注来源；不含付费课程内容。

## 一、三条判断心法

**1. 判断力永远高于执行力。** AI 能写文案、剪片子的时代，最稀缺的不是会干活的人，是能判断 AI 干得对错的人。方法可被工具替代，判断不能。（与秒赞"术中有道"、真需求"认知是因"同向）

**2. 先问真需求，再谈方法。** 一件事能成是因为符合别人的真需求，能做大是因为受益者多。（《真需求》全书主命题）做任何内容前先过：这戳中谁在什么处境下的什么需求？他能得到什么？——而不是"我想表达什么"。

**3. 默认没人跟你共鸣——是你去共鸣观众，不是让观众来共鸣你。** 三大默认素养：你的观点没那么牛逼、你的生活别人并不羡慕、没有人天然跟你共鸣。卸下"我很特别"的幻觉，才能真正研究观众要什么。

## 二、价值判断三看（做什么之前先看）

用《真需求》的价值公式判断你交付的是什么价值，用户为什么付钱/为什么看：

**产品价值 = 功能价值 + 情绪价值 + 资产价值**

- **功能价值**：人们为功能付费本质是买**更高效率**。功能产品最怕做成"匪兵甲"——没效率优势、主角一出即被淘汰。
- **情绪价值 = 生理唤起 + 认知标记 + 心理账户**。付费点三选：**保障感**（对抗担心）、**愉悦感**（对抗枯燥）、**彰显性**（对抗自卑）。情绪产品最怕做成"貂丁"——每点都能自圆其说、凑一起是笑话。判断标准：三个付费点能否**确定性交付**一个？
- **资产价值**：可持续变现就有资产价值，需要**专门市场 + 共识**。多数个人 IP 的内容没有资产价值（内容无法二手交易），别硬造。

**主价值只选一个**，不为填表硬凑。

## 三、可信度红线（营销与诚实的边界）

- **承诺可交付**：你承诺的核心点（期望属性）能确定性交付用户就满意；不能交付就是智商税，无论初心。（KANO：期望属性必须确定性交付）
- 医疗/心理/法律/财务/收益类表述：只做内容框架，不承诺效果、不编造资质与数据。
- 不用恐惧、羞耻、群体对立、弱势群体操控制造流量。
- 区分事实/推断/未知；信息不足标未知并给最小验证。

## 四、反模式（最常见死法，看到就停）

- **自嗨**：把内容当单向自我表达，不研究观众要什么。
- **卖什么不说什么**：做穿搭却通篇聊情感引流——内容必须扣回变现物。
- **火了但方向错了**：涨了一堆你不想要、转化不了的粉，比没流量更致命。追流量前先验证方向。
- **只同屏不突出**：只让观众觉得亲切，看不见你继续被看的价值。
- **复制爆款失去信念感**：爆过的壳子最危险，它诱惑你不再真投入。信念感是表现力的本质。
- **把内容当文字游戏**：交流感 > 文字技巧，观众要跟真人交流，不是看作文。

## 五、心法速查

| 场景 | 问自己 |
|---|---|
| 想做一条内容 | 这戳中谁的什么真需求？他能得到什么？ |
| 用户不行动 | 为什么不动？是感知、想象、场景还是利益的问题？（真需求·分歧四源） |
| 要承诺一个卖点 | 我能确定性交付吗？不能=智商税 |
| 感觉定位模糊 | 我的记忆锤是什么？观众记住我的哪一句？ |
| 播放高不转粉 | 主验证目标对吗？是人群错、未来价值弱，还是主页承接断裂？（先归因再动手） |
