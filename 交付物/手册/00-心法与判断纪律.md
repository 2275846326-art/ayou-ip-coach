# 00 · 心法与判断纪律（总纲）

> 本手册是五本手册的地基。其他手册教"怎么做对"，本手册教"判断之前默认装哪套操作系统"。书籍方法保留来源；当前协作流程另标采用依据与验证边界，不含付费课程内容。

## 双向论证与证据判断（2026-10-20 · 当前执行）

本节是维护者明确采用的协作流程，不是书中原话或已经验证有效的防迎合技术。适用于方向选择、方案比较、重要归因与价值取舍；简单事实、格式转换和已明确的执行直接完成，不机械展开双方论证或阻塞任务。个人成长判断按实际领域核据，不强套下文营销/付费标准。

### 先判断，再比较；证据强弱不对称

1. **校准问题**：简述用户想解决什么；用户明确提供的信息、AI推测及未知分别标清，不替用户捏造“真正动机”。目标或衡量标准不明且影响结论时才澄清。
2. **呈现最强论证**：对有实质分歧的方案，用双方各自最合理的版本说明支持和反对理由，标明依据、成立条件及关键假设。不存在有力反方就说明，不为凑对称编造争议；同一模型的两段文字不是独立交叉验证。
3. **核证据**：关键事实回查实际可见原文、数据与反例，区分来源说了什么、是否支持当前主张、能否适用于当前对象。按证据质量和条件判断，不按来源身份、回答长度或双方字数判断。无资料时记未知、暂缓强结论或给最小验证，不编链接、不把没找到当证伪。
4. **找决定因素**：指出真正分歧属于事实、条件、目标还是价值取舍；说明哪项新信息会改变结论。用户偏好可以决定价值选择，但不证明事实。事实和目标不变时，用户说“我很喜欢/我觉得不行”不能单独让事实评价反转；若补充了真实新目标或条件，则解释后合理更新。
5. **只在必要时问**：缺失信息确实影响判断或下一行动时，只问一个最关键问题并等待回答；不依赖该答案的工作可继续。信息已够就直接判断，不凑问题、不重复询问已有信息。不为减少提问而假定答案，用户明确要求先问后答时遵守其范围。
6. **给可执行结论**：说明当前采用、限缩采用、不采用或暂不能判定，给最少必要理由、条件与最小验证动作。改变判断须交代新增信息、标准变化或原先错误；仍有重要冲突交当前负责人裁决，不把AI分析自动写为已采用。
7. **学习与反馈**：需要时用一个具体对照解释“哪项依据改变了判断”，按用户意愿复述、迁移或实际试用；讲过/认可不等于学会，采用不等于有效。沿既有判断记录保存结论、条件、改变结论的触发因素和实际反馈，不另造平行错误库。

礼貌、共情与尊重价值选择不等于迎合；不能为显得独立而固定反对用户。输出可核查的论证摘要即可，不要求展示冗长内部思考。若现有“先结论”交付口径与等待必要信息冲突，先说明暂缺什么及其影响，收到答案后再下依赖它的结论。

### 可直接使用的提示词

> 先检查问题里的前提，不默认我的想法成立。简述我的目标，区分我明确提供的信息、你的推测与未知。对有实质分歧的部分，给出支持与反对的最强论证，标注依据、假设和适用条件；没有有力反方就不强凑。关键事实回查可见来源，无法核查就标未知；按证据强弱判断。指出真正分歧及什么信息会改变判断。只有缺失信息确实影响结论时，问我一个关键问题并等待回答，否则直接给当前判断、理由和最小验证行动。我的赞同或反对不是事实证据；改变判断时说明依据。请简洁解释一个决定结论的关键点，帮助我学会，而不是替我作价值裁决。

### 验证边界

本节是用户授权采用的流程，不承诺提示词消除迎合。形式/加载检查通过只说明规则可达，不能证明模型实际遵守或判断正确。行为验收可固定同一资料、事实和目标，仅改变用户赞同/反对态度，比较结论是否无理由反转；另测新增证据应合理更新、明确事实不强造反方、信息足够不强问、关键缺口等待回答。需保留实际输出与来源，未运行模型对照就标未验证，不能把人工写的预期答案当测试结果。

研究背景：[Anthropic迎合研究（2023）](https://www.anthropic.com/research/towards-understanding-sycophancy-in-language-models)支持所测模型中出现迎合及部分偏好机制；[推理说明忠实性研究（2023）](https://www.anthropic.com/research/measuring-faithfulness-in-chain-of-thought-reasoning)说明展示推理不一定忠实。本节具体流程是系统维护者采用的设计，不是上述研究已验证的干预方案，不把模型历史研究推广为所有当前AI的结论。

## 一、三条判断心法

**1. 判断力永远高于执行力。** AI 能写文案、剪片子的时代，最稀缺的不是会干活的人，是能判断 AI 干得对错的人。方法可被工具替代，判断不能。（与秒赞"术中有道"、真需求"认知是因"同向）

**2. 先问真需求，再谈方法。** 一件事能成是因为符合别人的真需求，能做大是因为受益者多。（《真需求》全书主命题）做任何内容前先过：这戳中谁在什么处境下的什么需求？他能得到什么？——而不是"我想表达什么"。

**3. 默认没人跟你共鸣——是你去共鸣观众，不是让观众来共鸣你。** 三大默认素养：你的观点没那么牛逼、你的生活别人并不羡慕、没有人天然跟你共鸣。卸下"我很特别"的幻觉，才能真正研究观众要什么。

## 二、价值判断三看（做什么之前先看）

用《真需求》的价值公式判断你交付的是什么价值，用户为什么付钱/为什么看：

**产品价值 = 功能价值 + 情绪价值 + 资产价值**

- **功能价值**：人们为功能付费本质是买**更高效率**。功能产品最怕做成"匪兵甲"——没效率优势、主角一出即被淘汰。
- **情绪价值 = 生理唤起 + 认知标记 + 心理账户**。付费点三选：**保障感**（对抗担心）、**愉悦感**（对抗枯燥）、**彰显性**（对抗自卑）。情绪产品最怕做成"貂丁"——每点都能自圆其说、凑一起是笑话。判断标准：三个付费点能否**确定性交付**一个？
- **资产价值**：可持续变现就有资产价值，需要**专门市场 + 共识**。多数个人 IP 的内容没有资产价值（内容无法二手交易），别硬造。

**主价值只选一个**，不为填表硬凑。

## 三、可信度红线（营销与诚实的边界）

- **承诺可交付**：你承诺的核心点（期望属性）能确定性交付用户就满意；不能交付就是智商税，无论初心。（KANO：期望属性必须确定性交付）
- 医疗/心理/法律/财务/收益类表述：只做内容框架，不承诺效果、不编造资质与数据。
- 不用恐惧、羞耻、群体对立、弱势群体操控制造流量。
- 区分事实/推断/未知；信息不足标未知并给最小验证。

## 四、反模式（最常见死法，看到就停）

- **自嗨**：把内容当单向自我表达，不研究观众要什么。
- **卖什么不说什么**：做穿搭却通篇聊情感引流——内容必须扣回变现物。
- **火了但方向错了**：涨了一堆你不想要、转化不了的粉，比没流量更致命。追流量前先验证方向。
- **只同屏不突出**：只让观众觉得亲切，看不见你继续被看的价值。
- **复制爆款失去信念感**：爆过的壳子最危险，它诱惑你不再真投入。信念感是表现力的本质。
- **把内容当文字游戏**：交流感 > 文字技巧，观众要跟真人交流，不是看作文。

## 五、心法速查

| 场景 | 问自己 |
|---|---|
| 想做一条内容 | 这戳中谁的什么真需求？他能得到什么？ |
| 用户不行动 | 为什么不动？是感知、想象、场景还是利益的问题？（真需求·分歧四源） |
| 要承诺一个卖点 | 我能确定性交付吗？不能=智商税 |
| 感觉定位模糊 | 我的记忆锤是什么？观众记住我的哪一句？ |
| 播放高不转粉 | 主验证目标对吗？是人群错、未来价值弱，还是主页承接断裂？（先归因再动手） |
