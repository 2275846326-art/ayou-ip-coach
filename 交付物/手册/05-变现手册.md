# 05 · 变现手册（任务手册）

> 判断"这个 IP 靠什么赚钱、内容怎么承接、先验证什么"。变现在内容之前想清楚，但别在信任没建立时急着收割。
>
> 方法来源（公开书蒸馏）：《真需求》拿谁的钱/变现逻辑/关系四层次、《超级符号》说动。

## 本任务解决什么

用户有内容/有粉丝/有产品，问"怎么变现"或"要不要接这个商单"。

## 第一步：先想清楚"拿谁的钱"

（真需求·第十二章"模式第一问"——最该先回答的问题）

一个生意能持续，必须从下面四个地方之一持续拿到钱，并控住成本：
- **to C**：用户直接付费（课程/咨询/带货/社群/打赏）
- **to B**：商家/品牌付费（广告/商单/代言/企业服务）
- **to VC**：资本的钱（融资——**对个人 IP 基本不适用，警惕误入**）
- **to G**：政府/机构（补贴/项目——少数人）

**判断金句**：靠资本的钱=拿最后一笔钱的日子就是终点（每日优鲜）；能持续从用户手里拿钱才是活法（瑞幸转向）。个人 IP 的稳健答案几乎都是 to C 或 to B，先别想 to VC。

## 第二步：关系到了哪一层，决定能卖什么

（真需求·关系四层次：需要→喜欢→认同→归属）

| 粉丝关系层 | 能变现什么 | 别急着卖 |
|---|---|---|
| 需要（你有用） | 低价工具型产品/服务 | 高价产品 |
| 喜欢（你有意思） | 中低价、低决策成本 | 需要深度信任的 |
| 认同（价值观一致） | 课程/社群/较高客单 | 尚未建立认同别上大货 |
| 归属（愿意为你说话） | 高价、长期、转介绍 | — |

**判断金句**：认同是消费者和粉丝的分界线，归属是散粉和核心的分界线。**复购用户才是让企业活下来的基本盘**——先问你的变现物有没有复购逻辑。

## 第三步：内容怎么承接（变现路径要设计，不是等）

**持续渗透，别想一次性成交。** 把内容当长期信任通道，信任攒够成交水到渠成。设计路径：
1. **主内容**：持续提供价值（吸对的人）
2. **承接内容**：定期讲"我怎么帮你解决问题/我的产品为什么能解决"（把观众导向你的方案）——**卖什么要说什么，内容必须扣回变现物**
3. **信任状**：真实案例、过程、结果（身教优于自夸）
4. **行动钩子**：主页简介/置顶/私信引导，把"刷到的人"变成"找上门的人"

**检查**：观众看完 10 条你的内容，知不知道"你能帮他解决什么问题、怎么联系你"？不知道=承接断了。

## 第四步：验证顺序（小步快跑，别一次押注）

1. 先验证**有没有人真的需要**（预售/咨询量/私信，而不是点赞）
2. 再验证**愿不愿意付小钱**（低价体验款）
3. 最后才上**完整高价产品**

**判断金句**：收藏≠需求，点赞≠购买。**付费的才是用户**（经纬语，方法同向）。要验证"愿意付钱"，去问有没有人掏钱，不是问"你觉得好不好"。

## 商单/合作判断清单（接不接）

1. 对方产品/品牌与你的人设、受众匹配吗？（不匹配=消费信任，别接）
2. 你的受众会是它的用户吗？（不是=广告给错人，两败）
3. 报价与你的真实影响力匹配吗？（粉丝数≠影响力，看真实转化）
4. 内容会不会伤害你的长期信任？（一次伤害性广告=多年积累受损）

## 反模式

- **没想清楚拿谁的钱就开干**：做到一半发现没人付费。
- **粉丝少时过早想变现**：先验证价值与信任，别急着收割。
- **接单只看钱不看匹配**：透支信任，涨错粉。
- **内容不扣变现物**：引流到无关方向，跑了也白跑。
- **把点赞收藏当需求证据**：那只是"觉得有用"，不是"愿意付钱"。

## 交付物

1. 变现路径判断：靠谁的钱、卖什么、现在能不能卖（还是先攒信任）
2. 内容承接设计：哪类内容负责引、哪类负责承接、行动钩子在哪
3. 信任状清单：有哪些真实证据可用
4. 验证顺序：第一步验证什么、怎么验证
5. 商单判断：接/不接/怎么谈

## 交付前自检

- 拿谁的钱想清了吗（C/B/VC/G）？
- 粉丝关系到了哪层，卖的东西匹配吗？
- 内容有承接路径吗？观众知道怎么找到你吗？
- 有复购逻辑吗？
- 第一步验证的是"愿意付钱"而不是"觉得不错"吗？
