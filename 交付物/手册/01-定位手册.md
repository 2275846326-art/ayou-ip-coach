# 01 · 定位与内容支柱（任务手册）

> 判断"谁来讲、服务谁、提供什么稳定价值、靠什么活"，并落成观众能从内容中感知的定位、人设与内容支柱。不是只改简介，也不把职业身份直接等同账号定位。
>
> 方法来源（公开书蒸馏）：《真需求》价值公式与用户人设、《超级符号》符号与一句话定位、《定位》心智占位。具体判断以档案事实与可验证证据为准。

## 本任务解决什么

账号定位不清、简介与内容脱节、观众记不住你、吸引来错误人群——先判断到底是**底座不清**、**内容没持续兑现**、**吸错人群**还是**证据不足**，不直接改一句话定位掩盖根因。

## 前置

已通过档案门（建档完成）。缺档案或建档未完成时先建档，不执行本任务。

## 决策路径

### 1. 拆五要素（按优先级）

1. **价值**：观众当下和持续能得到什么（对照 00 手册"价值三看"，主价值只选一个）
2. **用户**：具体到"一人一阶段一问题"，含约束、失败尝试、**不服务谁**
3. **人设**：观众为什么相信、记住、偏好这个人（不是自我介绍）
4. **类型**：讲述型/呈现型/配比，匹配真实能力
5. **风格**：最后决定的包装，不可反过来支配内核

> 内核=价值+用户+人设。职业、年龄、宝妈等身份只是证据和故事资源，不自动决定账号类型。

### 2. 锁双锚点

- **人群锚点（服务谁）**：不要写"普通人/女性/职场人"，要写正在经历什么、为何此刻点开、试过什么、愿意为什么行动。
- **变现/用途锚点（靠什么活）**：卖什么、导向什么业务，或为何不直接变现。赛道锁业务，人群锁内容；**只有一边都会漂**。

**定位可以窄，题材可以宽**：优先围绕同一类人的不同需求扩题材，不用同一题材假装垂直。

### 3. 判断记忆锤（超级符号方法）

观众对你的记忆是碎片堆积的。先问：**"说到你，观众脱口而出的是不是同一句话/同一个画面？"**

- 打造一个**最小记忆包**：每个人记得的都是同一片、一记就牢、能装载你的价值零损耗传播。
- 借符号不造符号：借观众**本来就记得、熟悉、喜欢**的符号/话语嫁接你的价值（如"天安门正南50公里"借天安门）。你不需要发明新东西让观众记，去借他早就记住的那个。
- 检查：你的标签是"可转述的"吗？能不能一句话说给朋友听？说不出来=传播成本高。

### 4. 人设变成可观察行为

人设是观众印象。先提供价值，再在故事/立场/关系/做事过程里让人设显现——**身教优于自夸**。

人设结构（真需求·人设公式）：**固定人物分类 + 记忆锤 + 外在形象特点 + 性格 + 特长**。其中记忆锤是"每次曝光都对着观众挥锤的落点"，只选一个。

五类记忆资产（身份/立场/视觉/语言/行为）中，**一个阶段只选 1 个主资产 + 最多 2 个辅助**。资历、成就、案例必须真实。

### 5. 落内容支柱

每条支柱必须连接"目标人群的一类问题 × 主价值 × 人设证明"，且能持续产题。四种内容动作组合使用：

- 晒过程：证明能力或质量
- 讲故事：证明可靠与经历
- 教知识：证明专业与方案
- 聊观点：证明理解与立场

默认给 3 条左右主支柱；每条说明服务哪个问题、观众得到什么、证明什么、可做的题型。**简介里的标签若无法在最近内容中直接看到，就不是有效定位。**

## 交付物契约

1. **定位结论**：一句话写清"为哪类人在什么阶段解决什么问题，凭什么由我"。
2. **目标用户**：具体状态、核心问题、不服务谁。
3. **价值结构**：主价值、当前价值、持续价值（对照价值公式）。
4. **人设**：真实证据、与观众关系、主记忆资产与红线。
5. **约 3 条内容支柱**：各自职责、题型、业务连接。
6. **首批只验证的一个变量** + 未知项标注。

## 失败与升级条件

- 真实经历/证据不足：把方向标为探索假设，设计首批验证，不包装专家身份。
- 多目标打架：要求选 90 天唯一主要目标，其余降为约束。
- 商业目标与想吸引的人冲突：直说冲突，优先修双锚点。
- 用户要彻底换定位：说明保留事实、变化原因、受影响模块；陪跑模式留修订记录。

## 交付前自检

- 是否把身份误当定位，或先定形式后补价值？
- 是否同时说清服务谁 + 靠什么活？
- 主价值是否具体、与类型业务相容？
- 记忆锤是否可转述、被观众感知？
- 人设是否由真实行为证据支撑？
- 每条支柱能否持续产题？
- 是否明确事实、假设、未知和首批验证？
