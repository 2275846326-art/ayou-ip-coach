# 方法边界与来源地图

版本：v0.4 · 2026-09-21。

## 来源与覆盖

本公开版包含已有通用手册中的规则、空白模板及工作流，不包含电子书全文、全套六层蒸馏、付费课程转写和完整论证。

原有14本的阅读完成情况来自历史项目记录，本轮发布未重新逐本审计。公开文件中的书名、章节和条目用于回查，不代表每个推论都经独立验证。新增尚未达标资料不作为本版来源。

| 主题 | 既有来源线索 | 使用目的 |
|---|---|---|
| 需求与定位 | 真需求、超级符号、定位 | 识别人群问题与差异 |
| 说服与信任 | 影响力、故事思维、思考快与慢 | 审视论证、信任与判断偏差 |
| 内容与体验 | 秒赞、行为设计学 | 内容组织与体验设计 |
| 增长与表达 | 增长黑客、金字塔原理、麦肯锡结构化、奥格威导读 | 实验、结构与表达 |
| 人群与社会 | 社会学的邀请、乌合之众 | 分析处境和群体影响 |

此表是来源导航，不代替精确章节定位；具体条目缺少足够依据时应降低断言强度或暂不引用，不能用AI记忆补成作者原话。

## 三种状态分开

- 来源核对：材料是否取得，具体段落是否对照。
- 使用状态：是否获当前负责人确认可用于指定场景。
- 效果验证：是否有实际案例、反馈、样本范围和反例。

可直接使用不等于普遍有效；暂未实战也不意味着有条件的写作工具一律不能用。事实、作者主张、系统转化与假设分别标明。

## 判断边界

1. 方法服务受众与任务，不靠固定字数、反常识句式或宏大结尾强制统一风格。
2. 先收集事实，再追问因果；没有预算、过程、结果等关键资料时不编诊断。
3. 观点和标题不得伪装事实，不虚构经历、资质、数据、产品性能或收益。
4. 个人经历不能自动证明群体规律；单次成功不能证明因果。
5. 高风险领域的内容框架不替代专业判断；避免未经证实的效果承诺。
6. 方法不等于当前IP本人声音；身份、称呼和观点来自对应档案。

## 更新规则

新来源先检查内容与公开范围，再决定采用、改造、保留研究或不采用；不因完成摘要就自动并入正式规则。导师观点冲突先比较适用场景，真正冲突由当前负责人裁决，保留双方依据。

更新记录应说明版本、改动原因、影响范围、实际检查和未验证部分。个人经验留在对应档案；拟公开的通用规则单独审查，私核不进入发布副本。
