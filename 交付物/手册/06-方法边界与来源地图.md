# 06 · 方法边界与来源地图（任务手册·元信息）

> 本手册不教"怎么做"，教"这套系统的知识从哪来、边界在哪、什么时候该信、什么时候要怀疑"。所有使用本系统的判断，都该先过这一层。
>
> 版本：v0.3（2026-09-05）——14 本全部升级为 A 档（全文逐字读完 + 六层蒸馏）后的刷新版。

## 一、方法来源与精读等级（诚实标注）

本系统的方法来自公开出版书的蒸馏。**14 本已全部达到最高精读档**（正文逐字读完 + 索引/主命题/分章命题/可调用条目/边界证伪/转化件六层完整蒸馏），因此不再存在"B/C 档待读"——现在的分级按**书在体系里的职能**划分：

| 组 | 书（蒸馏文件） | 在体系里管什么 |
|---|---|---|
| **需求与占位** | 真需求、超级符号、定位 | 做什么生意/占心智哪个位置/符号系统 |
| **说服与信任** | 影响力、故事思维、思考快与慢 | 用什么机制让人顺从/载体/大脑为什么吃这套 |
| **内容与体验** | 秒赞、行为设计学 | 标题怎么抓人/体验怎么设计峰与终 |
| **增长与执行** | 增长黑客、金字塔原理、麦肯锡结构化、奥格威导读 | 怎么放大/怎么结构化表达/行业价值观罗盘 |
| **人群与社会** | 社会学的邀请、乌合之众 | 人群的社会位置地图/群体心理 |

**使用纪律（14 本全 A 档后）**：
- 14 本的条目都已过"全文逐字读完 + 边界证伪"，**可直接写成判断规则**（进各手册与共享标准）。
- 引用具体条目时标来源（书 + 蒸馏文件号 + 条目编号），可回查原文验证——见各蒸馏文末"验收自测"。
- 本系统**不含**付费课程内容（安先生/经纬），其方法论在维护者私核区，只当面服务客户时调用。

## 二、跨书工具选择（这套系统最重要的元判断）

**听众决定用哪套工具。** 不同场景用不同书的方法，混用就错：

| 场景 | 用哪套 | 为什么 |
|---|---|---|
| 对 B 端/客户提案/汇报（听众要逻辑） | **金字塔/麦肯锡式**：结论先行、结构化、MECE | 理性决策者用左脑听，给结构=尊重他的判断 |
| 对 C 端/大众/短视频/广告（听众要直觉） | **超级符号式**：一句话说动、借符号、口语化；**秒赞式**标题 | 刷到的观众用右脑看，先唤醒本能再说理 |
| 判断"做什么生意/产品" | **真需求式**：价值公式+KANO+真需求 | 先验证需求再谈表达，避免自嗨 |
| 理解"人为什么不行动" | **真需求式**（分歧四源）+ **影响力式**（说服机制） | 归因要分清是感知/想象/场景/利益问题 |
| 打动人/建立信任 | **故事思维式**：6 类故事（我是谁/为何而来/愿景/…） | 理性证据建立"正确"，故事建立"信任" |
| 理解人群/选对表达对象 | **社会学的邀请式**：先看读者站在什么社会位置（收入×圈层×文化资本） | 品味是地位的产物，先懂位置再动笔 |
| 判断读者会怎么想 | **思考快与慢式**：系统1/2、锚定/损失厌恶/框架效应 | 预判读者 3 秒内的本能反应，设计防错/引导 |
| 设计转化与增长 | **增长黑客式**：北极星指标/试验循环/语言-市场匹配 | 把运营从玄学变成可测的试验机器 |
| 让一次体验被记住 | **行为设计学式**：峰值+结尾、打破脚本 | 记忆只记峰与终，结尾决定评价 |

**一句话**：先想"对面是谁、他在用什么脑子听"，再选表达工具——用超级符号的话术去做 To B 提案，或用金字塔结构去做短视频，都会错位。

## 三、14 本读完后的"最锋利一刀"（统一红线）

14 本来自不同领域，但**每一本都划出了同一条线**——这条线值得单列：

> **所有方法（符号/故事/标题/框架/助推/锚定/体验设计）都只能"放大真实"，不能"伪装事实"。**
> 故事思维说"故事家与恶棍隔一层窗户纸"；影响力说"伪造触发信号是敌人"；思考快与慢说"框架只能放大事实不能翻转事实"；奥格威说"真实性无法交易"；行为设计学/增长黑客/社会学的邀请在各自领域都指向同一句。

**使用纪律**：选择讲哪些真实 + 怎么讲 = 合法；编造资质/数据/案例/收益 = 越界（即使短期有效）。任何方法过了这条线，就从"方法"变成"操纵"。

## 四、必须守住的另外两条边界

1. **高风险领域只做框架**：医疗/心理/法律/财务/投资类内容，只提供表达框架，不承诺效果、不替代持牌专业意见。
2. **"我"的声音是系统的上限**：任何一条判断在变成"你的话"之前，都要过一遍"这与我的真实经历/证据一致吗"。方法给你框架，证据给你底气，两者缺一，宁可标未知。
