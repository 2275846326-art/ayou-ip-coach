# 10-图文内容逻辑

> **版本**：v1.0（2026-09-05）
> **状态**：通用参考规则；来源沿用历史记录，本轮未逐本重新核验。固定篇幅与结构按场景调整。
> **归属**：底座共享标准——**不属于任何平台项目**；公众号长图文与小红书图文结构不同，但底层逻辑同源。
> **一句话**：一篇图文 = 故事让读者"愿意读"（信任与情感）× 金字塔让读者"读得懂"（结构与逻辑）× 峰终让读者"记得住"（体验设计）——三者缺一不可。

---

## 0. 判断逻辑同源（先读这个）

无论长图文还是小红书图文，一篇内容都按同一套"三通道"设计：

```
通道 1  信任与情感（为什么听你）→ 故事思维：先答"我是谁/我为何而来"，再讲"像你一样的人"的故事
通道 2  结构与逻辑（为什么信你）→ 金字塔原理：结论先行，论点互不重叠、合在一起穷尽（MECE）
通道 3  记忆与行动（为什么记得/为什么做）→ 行为设计学：峰值+结尾；给一个"一步就能做"的行动

先让读者不设防（故事）→ 再让他吸收（结构）→ 最后让他记住并行动（峰终）
顺序不能反：先抛结构 = 像广告，先抛干货 = 旧故事会歪曲它（故事思维 S2）
```

---

## 1. 全篇骨架（通用母版，长短图文共用）

```
【开头】钩子 + 承诺（3 秒抓住，说明"读这篇能得到什么"）
   ↓
【入口故事】一个"像你一样的人"的具体个案（建立共鸣与信任，T5：讲道理用惊人个案不用统计）
   ↓
【观点/干货主体】金字塔结构（结论先行，3-5 个支撑点，每点一个论证+一个例子）
   ↓
【反例/边界】这方法在什么情况下不适用（防杠 + 显专业 + 真实）
   ↓
【结尾峰值】金句/升华/最有记忆点的一句（峰终定律：结尾决定评价）
   ↓
【行动召唤】一个极简的下一步（关注/收藏/评论/私信/下单——降低启动门槛）
```

---

## 2. 开头 3 秒（决定生死）

### 判断
读者先用系统 1（快思考）决定"要不要继续"——开头不抓住，后面再好也白写。

### 开头四式（一次用一式）
1. **结果前置**："这篇能帮你把 XX 从 A 做到 B，只讲能落地的 3 步。"
2. **故事开场**：直接进"像你一样的人"的具体场景（不说"我有一个朋友"，直接进画面）。
3. **反常识提问**："你以为做号最重要的是内容？不是。"
4. **身份召唤**："给一个人做工作室的你……"（筛选对的人，社会学的邀请 H1）

### 红线
- ✗ 空泛开场（"在当今社会…""随着…发展"）
- ✗ 承诺不兑现（开头说 5 个方法，正文只有 2 个）
- ✗ 自嗨开场（讲自己多厉害，读者不知道跟他有什么关系）

---

## 3. 正文结构（金字塔 + 反例）

### 判断
读者不是来听你"想说的"，是来拿他"想要的"——结构要让他 30 秒能扫到重点，5 分钟能吸收完。

### 可执行规则
- [ ] **结论先行**：每部分先给结论/方法名，再展开论证（金字塔：先总后分）
- [ ] **3-5 个论点**：超过 5 个读者记不住（组块化：短期记忆 4±1）
- [ ] **每个论点 = 判断句 + 为什么 + 例子/证据**（可调用条目格式，直接可抄）
- [ ] **论点互不重叠**（MECE：像搭积木，不重不漏）
- [ ] **小标题可扫读**：读者先扫小标题，有兴趣才细读（小标题本身就是骨架）
- [ ] **每个观点配一个具体例子**：抽象原则 + 具体案例（双编码：具体词激活视觉+语言，思考快与慢）
- [ ] **主动写"不适用"**：这个方法在什么情况无效——反例让专业度立住（阿柚体系真实铁律的落地）

### 图文专属
- **小红书图文**：一图一观点，图即标题，正文承接；图片是"可扫读的金字塔"——每张图一个论点。
- **公众号长图文**：段落间要有"为什么读下去"的衔接（钩子不能只在前头，每 2-3 段埋一个小钩子）。

---

## 4. 峰值与结尾（决定记忆与评价）

### 判断
读者对一篇内容的评价 ≈ 峰值（最爽的点）+ 结尾（最后的感觉）——过程再平，只要结尾有力，评价就高（峰终定律，行为设计学 E1/思考快与慢 T7）。

### 可执行
- [ ] 全篇设计 **1 个峰值点**（最扎心/最有用/最出乎意料的一个点，放在中后部）
- [ ] 结尾给一句**可记忆的金句**（读者带走的那句话）
- [ ] 结尾**呼应开头**（开头承诺 → 结尾兑现，形成闭环）
- [ ] 结尾**情绪向上**（哪怕讲问题，结尾要有希望与出路——故事思维 S10：别恐吓，给希望；社会学的邀请 H12：诊断配希望）

### 结尾三式
1. **金句升华式**：一句可截图的话收尾。
2. **行动收束式**："今天就做这一件事：……"（极简行动）。
3. **钩子延续式**："下一篇讲 XX，想看扣 1"（为下一期留扣）。

## 5. 分平台差异（判断逻辑不变，参数变）

| 维度 | 公众号长图文 | 小红书图文 |
|---|---|---|
| 单篇定位 | 深度信任建设（读完=深度连接） | 快速价值+人设曝光（3 秒停拇指） |
| 篇幅 | 1500-3000 字可读 | 图 6-10 张 + 正文 300-800 字 |
| 信息单位 | 段落（读） | 单图（扫） |
| 结构呈现 | 标题层级+段落 | 每图一个观点（图即金字塔层） |
| 故事位置 | 开头入口 + 穿插 | 单图故事（1-2 张图讲完一个"像你一样的人"） |
| 干货密度 | 高（可深） | 中（每篇一个核心方法即可） |
| 行动召唤 | 关注/在看/评论 + 文末转化 | 收藏（工具属性）/关注/评论引导 |
| 发布节奏 | 低频高质（周更可） | 高频（日更多图） |

### 关键提醒
- **小红书别把公众号长文拆成图就发**——图文的"图"要有独立信息量（不是文字截图），每张图讲一个能单独被收藏的点。
- **公众号别学小红书的碎片钩子**——读者在公众号是"主动选择深读"，给足结构与深度才不负期待。

## 6. 全篇自检清单（发布前过一遍）

- [ ] 开头 3 秒抓住并承诺了结果？
- [ ] 有"像你一样的人"的入口故事（信任）？
- [ ] 结构结论先行、3-5 点、不重不漏？
- [ ] 每个观点有判断+为什么+例子？
- [ ] 有"不适用"边界（显真实）？
- [ ] 有 1 个峰值点和 1 句结尾金句？
- [ ] 结尾给了希望/出路？
- [ ] 有极简行动召唤？
- [ ] 视觉上可扫读（小标题/单图单观点）？
- [ ] 内容兑现开头承诺（不注水）？

---

## 7. 边界与不适用

- **不适用 1**：纯新闻/资讯速递（不需要信任通道，直接给信息——但"峰终"仍适用）。
- **不适用 2**：硬转化落地页（目的是点击下单，结构要极简，故事退位给利益点+信任状）。
- **不适用 3**：客户已有强人设、粉丝为"人"而来时，可减少故事铺垫（老粉直接要干货）。
- **红线**：图文结构可以设计，**事实与观点不能伪装**——入口故事里的案例必须真实（哪怕匿名），数据必须可核验。这与《协作共识与版本流转协议》的红线一致：故事负责让真相被看见，不负责把假象包装成真相。

---

## 8. 验证方法

- **读完率/收藏率**：小红书收藏率=工具价值（结构好不好）；公众号读完率=内容是否接得住开头承诺。
- **评论质量**：评论里出现"这就是我/我朋友就是这样" = 入口故事成功。
- **金句被引用**：有没有读者截图你的结尾金句转发 = 峰值成功。
- **行动数据**：关注/私信/转化是否提升 = 整体逻辑是否跑通。
- **AB 测试**：同一选题换开头（故事式 vs 结论式），看数据定偏好。
