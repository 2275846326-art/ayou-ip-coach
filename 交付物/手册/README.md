## 使用顺序（一次会话的典型流）

1. 用户有模糊想法 → **02 选题**判"做不做"
2. 决定做 → **03 写稿**出成品
3. 发之前 → 签**契约模板**（赌什么/控制变量/失败信号）
4. 数据回来 → **04 复盘**逐条对账，结论沉淀进档案
5. 定期 → **01 定位**校准方向 / **05 变现**检查业务路径
6. 所有判断 → 回 **00 心法**找地基

## 方法来源声明

各手册判断来自《真需求》《超级符号就是超级创意》《定位》《秒赞》等**公开出版书**的原创蒸馏，条目标来源书名/章节可回查。不含付费课程内容。不编造资质、数据、案例、收益。
