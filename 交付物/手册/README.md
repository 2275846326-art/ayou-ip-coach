## 使用顺序（一次会话的典型流）

1. 用户有模糊想法 → **02 选题**判"做不做"
2. 决定做 → **03 写稿**出成品；排版前查 **08 封面**、发布前查 **09 标题**
3. 结构拿不准 → **10 图文内容逻辑**（公众号/小红书都读同一份，只改参数）
4. 发之前 → 签**契约模板**（赌什么/控制变量/失败信号）
5. 数据回来 → **04 复盘**逐条对账，结论沉淀进档案
6. 定期 → **01 定位**校准方向 / **05 变现**检查业务路径
7. 所有判断 → 回 **00 心法**找地基；拿不准信到什么程度 → 查 **06 边界手册**；接新客户 → **07 问诊**
