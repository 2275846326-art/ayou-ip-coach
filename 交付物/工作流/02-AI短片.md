# AI短片流程

版本：v1.0 · 2026-09-21。这是柚导工作方式的通用流程说明，不含本地技能安装包、私有知识库连接、项目专属设定或生成接口。

## 开始于当前阶段

先读项目已有记录：创作意图、目标观众、人物关系、事件、时长画幅、风格声音、已确认资产和已通过片段。区分用户确认、创作提案、素材实见和未知。不要为套流程重做已确认成果。

表达方法帮助确定观众要理解什么；镜头必须进一步落实为可见事件与表演。文章逐句配图不能自动形成完整叙事，纯展示镜头也不必强塞戏剧冲突。

## 制作主线

| 阶段 | 需要解决的问题 | 可交付结果 |
|---|---|---|
| 意图与事实 | 对谁表达什么；哪些是事实、哪些是虚构 | 主题、事实边界与项目目标 |
| 事件因果 | 谁做什么、遇到什么、如何回应、造成什么 | 事件表，前后段的因果关系 |
| 观众信息 | 开头知道什么，结尾多知道什么 | 信息安排与必要伏笔 |
| 表演声音 | 情绪由什么触发，如何被看见听见 | 动作、视线、台词、语气与对方反应 |
| 资产空间 | 谁是谁，在哪，谁拿什么 | 已确认参考与空间关系 |
| 生成任务 | 当前平台怎样执行这段事件 | 参考、模式、秒数、提示词与验收点 |
| 成片验收 | 结果是否真的发生、是否连贯 | 可用时段、真实末态、问题与最小修复 |

完整短片开发应提供视听规划，连接情绪目标、镜头疏密、音乐与声音；设计目标不冒充观众测试。生成素材总时长与成片使用时长分别记录。

## 单段任务卡

- 本段事件与版本。
- 已确认参考及用途；缺失的关键参考明确标出。
- 当前平台、模式与限制，依据当前实测或官方资料核对。
- 时间安排、动作、说话者、听者反应与结束状态。
- 只包含本次可见可听内容的生成提示词。
- 人工剪辑与操作另列，不混入模型指令。
- 验收点、接续对象、失败后优先修哪里。

不保证多格参考被逐格复刻，也不以“高质量、有情绪”等词替代动作设计。不把图中错误身份当作后续参考。

## 验收与迭代

先检查事件与因果，再检查身份、空间、动作连续、表演声音及节奏。抽帧不能证明完整运动和声音合格；没有看到实际视频就不宣称验收通过。

优先保留合格部分：后期可修则标时码；局部可补则保留接点；设计本身不清楚则改事件。连续同类失败时检查参考与动作设计，不盲目重复生成。

项目偏好写项目记录；知识库新增方法按来源、适用范围和实际问题评估后使用。上游事实、身份或故事改变时，只复核受影响的下游任务；不能因为知识更新就全部重做。

本流程不包含视频额度、自动生成或自动剪辑能力，也不承诺一次出片。
