# AYOU 蒸馏 · 用户入口

普通用户只安装 [ayou-distill](ayou-distill/SKILL.md)。它负责原文取材、六层蒸馏、来源核查和使用反馈，不要求用户选择多个版本。

你可以学习自己的书籍/课程，形成有来源和边界的方法，修正已有蒸馏、积累个人判断。成果放在你自己的知识库中，不因使用本工具就上传给维护者或公开仓库。

系统框架与底层工具的迭代由维护者负责；相应维护工具不随用户包交付。你只需表达需求、提供材料、检查是否准确，并反馈实际使用结果。

先提供可核查原文，新材料先交结构地图，确认后再继续。链接取材、ASR/OCR和软件权限仍取决于实际环境；没有取得全文就不能声称完成蒸馏。
