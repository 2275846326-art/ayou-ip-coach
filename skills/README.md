# AYOU 蒸馏技能：两个独立版本

作者：阿柚。基于 [ayou-ip-coach](https://github.com/2275846326-art/ayou-ip-coach)，本目录采用专有权利声明，**保留全部权利，使用需另获书面授权**，见 [LICENSE](LICENSE)；不适用根目录 CC 许可。v1.2.0 增加双版本与 IP 知识系统联动机制。

| 版本 | 安装目录 / 技能名 | 用途 |
|---|---|---|
| [纯蒸馏版](ayou-distill/SKILL.md) | `ayou-distill` | 书籍、视频字幕、播客、课程、长文取材，六层蒸馏、来源核查、能力构造与任务评测 |
| [IP 知识系统联动版](ayou-distill-ip-system/SKILL.md) | `ayou-distill-ip-system` | 共享蒸馏核心，额外对照已有系统产生方法增量、任务回归、版本迭代与反馈回流 |

权利人自用或已取得明确书面授权的使用者，安装时把所选技能文件夹放进 Codex 的 `~/.codex/skills/`；可以同时安装。只蒸馏调用 `$ayou-distill`，需要联动系统调用 `$ayou-distill-ip-system`，同一任务选择一个入口。

联动版先发现使用者自己的权威知识底座、系统入口、手册和裁决/发布协议；不会附带维护者私人档案或假设所有人使用同一路径。每次实质蒸馏形成系统影响报告；无增量则记录原因。候选规则经过核查、实际任务回归和现行授权后写回；使用反馈反向补方法边界和测试。模型测试通过不等于经营效果已证实。

两版均需要可核查文字来源。视频可尝试获取字幕，无字幕时衔接可用转写服务；工具不内置 ASR/OCR，不保证任意视频链接可获取。

公共核心维护在纯版，联动专属参考与脚本维护在联动版。运行 `python tools/build_ayou_variants.py` 同步公共核心并生成联动入口；两版分别安装、分别验收。工具只检查文件与基线，不自动批准系统变更。

设计借鉴 [cangjie-skill](https://github.com/kangarooking/cangjie-skill) 的能力与评测思想，结合阿柚六层标准独立实现，不复制其代码、书籍实例或数据 schema。
